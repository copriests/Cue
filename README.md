# Cue · React Native iOS teleprompter

A working-source prototype built with Expo/React Native and a local Swift module.
The project has not been compiled in Xcode or tested on an iPhone yet. Native
speech and PiP behaviour are experimental; this is not an App Store-ready binary.

## Included

- Script library stored locally using AsyncStorage; autosave, titles, multiple scripts.
- Dark rehearsal screen; countdown, pause/resume, restart, 40–300 wpm, text sizing, mirror mode.
- Swift-native timer, renderer and voice matching, independent of background JS timers.
- English (UK) on-device recognition only: no silent cloud fallback. iOS may require language resources.
- Bounded forward-only matching of partial speech; pauses when you stop speaking.
- Public AVKit sample-buffer Picture in Picture implementation rendering text as video.
- PiP play/pause and skip delegate handling; explicit microphone interruption messages.

## Run on your iPhone (Mac required)

1. Install current Node LTS, Xcode and its command-line tools. Open Xcode once to finish setup.
2. Unzip, open a terminal in this folder and run:

   ```sh
   npm ci
   npm run prebuild:ios
   npm run ios -- --device
   ```

3. In Xcode, choose your Apple development team if signing asks for one. The generated workspace is `ios/Cue.xcworkspace`.
4. Permit microphone and speech recognition when using Follow my voice.

Use `npm start` for subsequent Metro sessions. This requires a **development build**;
Expo Go does not include the custom Swift module. Rebuild after native changes.
The `ios/` folder is generated by Expo prebuild and is deliberately not included.
App identifier `com.copriests.cue` is a proposed development identifier; change if needed.

## Use

Write a script → Rehearse → choose Timed or Follow my voice → Start.
After the countdown, tap Float script and switch to Camera. The script window is
visible on screen; it is not intentionally composited into Camera's saved video.
Verify this on your device, including screen-recording differences.

PiP is an iOS-controlled opaque video window, not a transparent always-on-top
text layer. iOS controls its position, size, controls, and whether it can start.
Voice mode needs foreground permission first. The PiP play control cannot silently
reacquire microphone permission: return to Cue and tap Start after an interruption.

## Critical platform limits

- Another recording app can interrupt Cue's audio session. Simultaneous voice
  tracking and native Camera microphone recording is **not verified or promised**.
- Timed PiP over Camera is the first device feasibility test. PiP can be stopped or
  suspended by iOS or other media apps; continuous background rendering needs testing.
- Speech recognition sessions may finish or fail; Cue pauses and asks you to restart.
- Matching uses exact normalized phrases, with bounded lookahead. Skipping large
  passages, paraphrasing, number formatting and recognition errors may stall tracking.
- English UK only in this prototype. Long scripts render only the next 40 words.
- No in-app camera recorder, speech transcript history, export, cloud sync, or payments.
- Script files are local, unencrypted AsyncStorage in the app sandbox; iOS backups
  may include them. Do not describe this as encrypted storage.
- Background audio and PiP use for a text teleprompter must be assessed for App Review;
  approval is not guaranteed. No private APIs or video-call impersonation are used.

## Validation

```sh
npm run typecheck
npm test
npx expo config --type public
npx expo-modules-autolinking resolve --platform apple
```

These checks do not compile Swift or establish device compatibility.
Swift matcher tests are included; run `swift test` on a Mac with Swift 5.9 or newer. They have not been executed in this Linux environment.
See `DEVICE_TESTS.md` before distribution.

## Structure

- `App.tsx`: editor, library and rehearsal interface.
- `src/native.ts`: typed Expo module wrapper, graceful native-build warning.
- `modules/cue-native/ios/CueNativeModule.swift`: audio, speech, PiP and frame rendering.
- `modules/cue-native/ios/ScriptTracker.swift`: speech-to-script alignment.
- `app.json`: permissions, background mode and app configuration.
